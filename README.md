High Street Fashion
High Street Fashion is a static fashion e-commerce website that presents clothing, footwear, and body-spray categories in a simple storefront layout.
Features
Homepage for browsing the store
Product and category pages for:
Shirts
T-shirts
Trousers
Shoes
Body spray
About and Contact pages
Styling with CSS
Font Awesome icons
Product imagery from local assets and Unsplash
WhatsApp links for contacting the store
Built With
HTML5
CSS3
Font Awesome
Unsplash images
Git for version control

Getting Started
This is a static frontend project, so no backend server or database is required to view the pages.
Option 1: Open in a browser
Extract the project ZIP file.
Open the project folder.
Double-click index.html to open the homepage in your browser.
Option 2: Use Visual Studio Code
Open the project folder in Visual Studio Code.
Install the Live Server extension if it is not already installed.
Right-click index.html.
Select Open with Live Server.
How It Works
The HTML files define the pages and their content. The shared CSS file controls the visual styling and layout. Images and icons provide the visual elements, while WhatsApp links can direct visitors to contact the store.
Current Limitations
This is a static frontend website.
No backend or database is included.
A functional shopping cart, checkout flow, and payment processing are not included.
Product information is presented through the website pages rather than managed through an admin panel.
Future Improvements
